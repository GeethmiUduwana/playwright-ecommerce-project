# 🧪 Playwright E-commerce Test Automation Project

This project is an end-to-end (E2E) test automation framework built using Playwright for testing an e-commerce demo web application.

## 🚀 Features

* Automated login functionality (valid scenarios)
* Add to cart functionality
* Complete checkout process
* Page Object Model (POM) design pattern
* Reusable test data management
* HTML test reports with screenshots and videos

## 🛠️ Tech Stack

* Playwright (JavaScript)
* Node.js

## 📂 Project Structure

* `tests/` → Test cases (login, cart, checkout)
* `pages/` → Page Object classes (UI actions)
* `utils/` → Test data and reusable utilities

## ▶️ How to Run

```bash
npm install
npx playwright test
npx playwright show-report
```

## 📊 Test Coverage

* Login validation
* Cart functionality
* Checkout workflow

## 🎯 Purpose

This project demonstrates practical QA automation skills including UI testing, framework design, and test execution using Playwright.
